# 项目记录示例

此文件用于说明应记录哪些信息。已有项目请维护自己的记录；此技能不预设 SSH 地址、用户名、设备序列号或采集许可。

## 硬件和输入

- 机械臂型号、follower ID、有效关节标定文件位置、URDF 版本和相机安装 link。
- 实际执行臂与 leader 的区分；安装 link 对俯仰、滚转、夹爪动作的现场跟随观察。关节寄存器一致与物理零位独立验证分开记录。
- 腕部与固定相机各自的物理安装、稳定设备路径、实际图像模式和处理方向。
- 标定板字典、ID 排列、标签旋转及实测尺寸；具体配置文件及对应参考照片。
- 如使用远程设备，在项目自己的非公开记录中保存连接方式。

## 当前状态

- 分别记录板配置、软件离线验证和真实标定是否完成，附对应 run／结果文件。
- 相机或机械臂被其他任务占用时记录暂停状态；用户明确恢复后再进入采集。
- 未参与拟合的验证数据、误差和适用分辨率。
- 训练／冻结／新验证的时间、模型与训练板位姿哈希；肩肘固定和改变肩肘两种范围分别记录 RMS、最大值及实测关节跨度。
- 桌边底座基准对应哪台臂，锚点定义、带符号尺量值、单位、方向、高度参考面；CAD 推算点与独立实测点分别记录。
- 最近一次已完成的外参与最新诊断 run 分开；新 run 正式训练／验证为零时明确“没有新外参”。
- 最新参数文件夹／ZIP、文件哈希、包内验证说明和仍缺的验收项目；历史压缩包不覆盖。
- 最后一次力矩读回、检查时间、相机／串口是否关闭，物理断电是否由现场报告或开关反馈确认；不要把历史状态当实时状态。
- 尚缺的输入与实现，例如纯相机采集入口、分辨率控制、固定相机到机器人底座的外参求解。

## 交接时的简要结论

分别回答：文件是否齐全、内参是否通过独立新图检查、外参在哪些姿态范围验证过、是否测过绝对定位／抓取误差、是否有运动问题以及最后停机状态。继续已有采集前查看项目自己的最新记录；不要把此示例或公开 skill 当作某台设备的当前状态。
